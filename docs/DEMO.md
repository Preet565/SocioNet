# Buildathon demo script

## 90 seconds

1. Start the API and web app with the commands in the root README.
2. Point out **100 citizens**, seeded communities, trust, and the live tick on Overview.
3. Click **Advance one tick**. Explain that this adds 100 full lifecycle traces and real state changes.
4. Open Social Universe. Select a node; explain that node size is derived influence and edges are actual relationship records.
5. Open Butterfly Lab and run **One rumor, two universes**. The experiment forks the same snapshot, not a prewritten animation.
6. Show the result: same seed, control/treatment metrics, delta, and earliest event divergence.
7. Open Information Ecosystem. Point to the fictional claim, evidence status, credibility, exposures, and event stream.
8. Select a citizen, then Agent Mind Explorer. Explain that memory, beliefs, and decision evidence come from the same backend state.
9. Apply a context card from Intervention Console, advance one tick, and refresh the event stream.

## Recovery

If the API is intentionally stopped, the frontend shows **Offline preview** and does not claim that preview mutations are live outcomes. Restart the API and use Sync, or reload the page.
